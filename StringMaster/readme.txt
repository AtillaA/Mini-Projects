## String Master

Initial readme for the String Master miniproject.

Planned to contain the following functionalities:
  - Formatting
  - Find Substring
  - Make changes on a String (Mutable vs. Immutable)
  - Swap Letters (Capital to Lower and vice-versa)
  - Split/Join Strings
  - Validator
  - Compress String
  - Text Wrapper

Open to further improvements.
