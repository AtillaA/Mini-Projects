## String Master

Initial readme for the String Master miniproject.

Planned to contain the following functionalities:
  - Formatting
  - Find Substring
  - Make changes on a String (Mutable vs. Immutable)
  - Swap Letters (Capital to Lower and vice-versa)
  - Split/Join Strings
  - Validator
  - Compress String
  - Text Wrapper

Open to further improvements.


String to Int Ex:

Input: s = "1337c0d3"
Output: 1337
Explanation:
Step 1: "1337c0d3" (no characters read because there is no leading whitespace)
         ^
Step 2: "1337c0d3" (no characters read because there is neither a '-' nor '+')
         ^
Step 3: "1337c0d3" ("1337" is read in; reading stops because the next character is a non-digit)
