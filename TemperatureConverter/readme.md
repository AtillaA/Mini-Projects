# Temperature Converter
-----------------------
A basic Angular browser application that converts any given temperature value dynamically.


## Features:
------------
- 3 input number fields for Celcius, Fahrenheit, and Kelvin.
- Initially, all fields are empty.
- As a value is typed into any temperature field, the application updates the other empty fields with corresponding conversion formulas, and displays them.
- In case of decimals, the application shows up to 1 decimal value.


## Development Environment
--------------------------
- Node.js	v24.18.0 (npm 12.0.1)
- TypeScript 5.8.3
- Angular	20.3.31
- Angular CLI/build tools	20.3.36


## Getting Started
------------------
1. Install dependencies (npm install)
2. Start the application (npm start)
